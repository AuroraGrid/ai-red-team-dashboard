# Commercial Packages

The public repository is the **Community Edition**. Paid offerings are separate deliverables or services and are scoped according to what the buyer actually needs.

The goal is not to sell the same two Python files at wildly different prices. The price increases with implementation effort, customization, reporting depth, support, and responsibility for delivering an assessment outcome.

## $15 — Starter Pack

For individual users who want a cleaner way to get started.

Typical deliverables:

- Community Edition setup guide
- configuration checklist
- starter red-team objective pack
- starter forecasting prompt pack
- quick-start command reference

This tier is a digital starter deliverable, not a managed service.

## $49–$99 — Pro Toolkit

For users who want more structured material around the Community Edition.

Potential deliverables can include:

- larger curated test packs
- reusable prompt/objective libraries
- evaluation checklists
- result-review templates
- configuration profiles
- lightweight documentation customized to the buyer's workflow

Exact contents should be specified at purchase.

## $199–$499 — Professional Package

For consultants, small teams, or technical users who need a more operational package.

Potential scope:

- guided setup
- custom provider/model configuration
- tailored authorized test objectives
- structured result-capture templates
- scoring/risk rubric design
- model-comparison workflow design
- reporting templates
- implementation review

This tier should only advertise features actually included in the scoped deliverable. It does not imply that every roadmap feature exists in the public repository.

## $750–$1,500 — Deployment Package

For teams that want help getting an internal evaluation workflow running.

Potential scope:

- environment and dependency setup
- provider/model integration assistance
- custom test categories
- organization-specific prompt packs
- configuration hardening
- workflow documentation
- handoff session
- limited post-delivery support window

The buyer remains responsible for providing authorized access, credentials, target systems, and internal approvals.

## $2,500–$5,000 — Authorized AI Red-Team Assessment

For organizations that want the assessment performed for them rather than buying a toolkit.

A scoped engagement can include:

- pre-engagement authorization and scope definition
- target/model configuration review
- custom adversarial objectives
- execution of authorized AI red-team tests
- findings analysis
- risk/severity classification
- evidence-backed remediation recommendations
- written findings report
- executive or technical debrief
- retest of agreed remediation items where included in scope

The exact price depends on target count, model count, test depth, reporting requirements, turnaround requirements, and whether deployment/custom integration work is included.

## What buyers are paying for at the higher tiers

Higher prices reflect service and accountability, not merely access to source code.

The value can come from:

- time spent designing the assessment
- technical setup and integration
- custom test construction
- manual review and interpretation
- evidence organization
- professional reporting
- remediation guidance
- stakeholder communication
- retesting and support

## What is not included by default

Unless explicitly written into a quote or statement of work, paid packages do not automatically include:

- unlimited testing
- continuous monitoring
- legal/compliance certification
- penetration testing of non-AI infrastructure
- access to customer systems without authorization
- guaranteed vulnerability discovery
- guaranteed model compromise
- guaranteed regulatory compliance
- unsupported claims of enterprise readiness

## Commercial inquiry process

For a commercial package, open a **Commercial inquiry** GitHub issue and provide only high-level, non-sensitive information:

- desired package or budget range
- number/type of models or applications
- whether you want a toolkit, deployment help, or an assessment
- preferred delivery format
- broad timeline

Do **not** put credentials, API keys, private prompts, customer data, proprietary system details, or sensitive security information in a public issue.

## Custom quotes

The listed prices are positioning ranges, not a guarantee that every scope fits inside them. A narrow engagement may cost less; a complex multi-target engagement may require a separate quote.

For any paid assessment, scope, authorization, deliverables, exclusions, and acceptance criteria should be written down before work begins.
