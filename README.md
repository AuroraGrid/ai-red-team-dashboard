# AI Red-Team Dashboard

**Simple toolkit for testing AI systems (authorized use only)**

This is a lightweight tool for evaluating how AI models behave under different instructions and for running structured probability-style questions.

It is designed to be small, inspectable, and easy to run.

---

## What it does

- Runs authorized red-team style tests against AI models
- Supports structured forecasting questions (probabilities, constraints, counter-arguments)
- Works with OpenAI-compatible model endpoints
- Keeps API keys out of the source code

---

## Important

**Only use this on systems and models you own or have explicit permission to test.**
